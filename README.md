# Master Shekar Ji | Vedic Wisdom & Spiritual Guidance

A modern, responsive Vedic Astrology and Spiritual Healing web application built with React, TypeScript, Vite, and Tailwind CSS.

## 🌟 Features

- **Vedic Astrology & Planetary Insights**: Ephemeris-based calculations and planetary positions.
- **Spiritual Healing & Services**: Comprehensive overview of services, pujas, and personalized guidance.
- **City & Timezone Lookup**: Interactive consultation booking with worldwide city support.
- **Cosmic Visual Effects**: Interactive cosmic particles and smooth UI animations.
- **Responsive Modern Design**: Optimized for mobile, tablet, and desktop experiences.

## 🚀 Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons
- **Backend / Database**: Supabase integration ready

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Pandu1712/Shekar-Astro.git
   cd Shekar-Astro
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
